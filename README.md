# ETHIOPIA AI

An open-source AI platform project focused on building useful AI assistants for Ethiopia.

## Initial languages

- Afaan Oromoo
- Afaan Amharic (አማርኛ)

## Vision

Build an extensible AI platform that can grow from a language assistant into multi-agent applications and, in later phases, robotics integrations.

## Project principles

- Start small and build step by step.
- Prefer open-source models and tools.
- Design for low-resource language support.
- Protect user privacy and handle data responsibly.
- Test each feature before expanding the system.

## Planned roadmap

1. **Foundation:** repository structure, documentation, and development guidelines.
2. **Assistant MVP:** a simple chat interface connected to a selected open-source language model.
3. **Language support:** evaluate and improve Afaan Oromoo and Afaan Amharic responses.
4. **Memory:** add optional, user-controlled conversation memory.
5. **Agents and tools:** add carefully scoped tools and task-specific agents.
6. **Robotics research:** explore safe interfaces to robotics platforms after the assistant foundation is stable.

## Current status

Early planning and repository setup. No AI model or production service is included yet.

## Contributing

Development is currently organized in small, reviewed steps. See the project issues and future contribution guidelines before submitting changes.
